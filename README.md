# TripCrew-AI
A-Multi-Agent-Travel-Planner-with-LangGraph

## How to run?

1. Create the Virtual Environment

```bash
uv venv --python 3.12
```

2. Activate the Environment

```bash
.venv\Scripts\activate
```

3. Install the Requirements

```bash
uv pip install -r requirements.txt
```
